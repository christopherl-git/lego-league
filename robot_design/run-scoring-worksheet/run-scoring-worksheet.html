Robot Run Scoring Worksheet

Full 2:30 test runs. Run it like the real match. Write down every run.

A full test run is a practice match: all six missions in order, with the 2 minute 30 second timer running. Each run gets its own run sheet. After a few runs, the summary pages show our average, best, worst and middle score, and which missions fail most often. That tells us what to fix first, and it is proof for the Robot Design judges.

Jobs for each run

  1. Driver runs the robot and swaps attachments. Timer starts the 2:30 clock and calls out the time. Scorer fills in the run sheet. Swap jobs every run.
  2. Reset the field exactly like the start of a match, with every model in its starting spot.
  3. Start the timer and go. When each mission ends, the timer calls out the time left and the scorer writes it in the Timer column.
  4. Stop at 0:00 even if missions are left. Missions not tried count as Failed, 0 points.
  5. Score each mission using the rule book, add up the total, and agree on the one change to make before the next run.
✓ Done
Did everything the mission asks and got full points.
½ Partial
Got some points but not all of them.
✗ Failed
0 points: missed, broke, ran out of time or not tried.

Rules that keep the numbers honest

  • Never skip a bad run. If we only write down good runs, our average lies to us.
  • Change one thing between runs (code, attachment or how we line up), so we know what made the difference.
  • Write down every time a hand touches the robot outside home. In a real match that can cost points.

Print one run sheet (page 2) for every run. Pages 3 and 4 collect all the runs together.

What the numbers tell us: is the average close to the max? If not, which missions keep dragging it down?

Why the median? One really bad run (robot fell over) pulls the average down a lot but barely moves the median. If the average is much lower than the median, we have a few disaster runs to look at.
